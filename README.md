## CSS is a lost art

Growing up I used to use a lot of VB Forums at probably far too young of an age, and the best part of it was they enabled CSS which means you got to customise your own little free corner of the internet, back when the internet was worth a damn. It's been bloody ages, but I still love and admire CSS. I'm going to challenge myself to make a little something in CSS every day, or over a couple of days if it's particularly ambitious, but I'm starting with baby steps here.

If this inspires anyone, go forth and make art.
